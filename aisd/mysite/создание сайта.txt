1. Устанваливаем django:python -m pip install django
2. Создание проекта: django-admin startproject "название1"
   Переход в рабочую область: cd путь к проекту
   Создание приложения: python manage.py startapp "название-приложения"

3. Создадие папки templates в корне для html, папки static для css визуала
4. В settings в установленных приложениях INSTALLED_APPS вписываем созданное "название-приложения"
5. В settings в static files вписываем папку нахождения файла css:
STATIC_URL = 'static/'
STATICFILES_DIRS = [BASE_DIR / 'static']
6. в settings в templates вписываем папку где находится html шаблом
'DIRS': [BASE_DIR / 'templates'] 
7. в views в папке с приложением указываем путь где находится html шаблон, чтобы он выводился по запросу
8. создаём фай urls в папке приложения указываем функцию html, чтобы она вызывалась при заходе на главную страницу
9. в urls где settings указываем маршруты, которые находятся urls в папке приложения
10. создаём html шаблон, указываем название, подключаем css, вписываем текст 
11. создание css с визуалом страницы
